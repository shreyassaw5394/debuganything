Every leaves evidence.

Debug Anything lets your AI agent look inside a running program, measure what is wrong and cite the evidence for every finding. It only looks. It never changes anything.

npx debuganything setup

The first bug report came with its proof.

At 15:45 on 9 September 1947, operators of the Harvard Mark II found a moth trapped in Relay #70, Panel F. They taped it into the logbook and wrote the time beside it: First actual case of bug being found.

Debug Anything files findings the same way. A time, a place in the running program, and the evidence attached, so your agent cannot claim what it did not see.

Tell it what you see.

How it works

First, it attaches to the process.

By pid, container, pod or a command it starts for you. Nothing is installed in your app.

$ debuganything attach 34327

session   s_7f3c2a

It works with Claude Code, Cursor, Codex, Gemini CLI, LangChain, LlamaIndex, CrewAI and your own on-call agent.

npx debuganything setup

One command registers the MCP server and both skills with each of them. For Python agents, pip install debuganything.

What it can see

It sees what holds your memory.

Array retains 87.7 MB, 93% of the heap. Evidence snapshot_memory#5/e5

It sees where the CPU time goes.

One frame takes 58.3% of CPU work: a file read on every request. Evidence profile_cpu#1/e2

It sees which threads are stuck.

worker_ab holds lock_b, worker_ba holds lock_a. Neither runs. Evidence dump_stacks#1/e14

It sees who holds the port.

Port 3000 is held by pid 61326 (node), left over from the last run. Evidence inspect_sockets#1/e1

It sees the sockets nobody closed.

412 sockets in CLOSE_WAIT: the peer hung up, the app never did. Evidence inspect_sockets#2/e2

Questions

Does it change my app?

No. It never kills, signals, patches or sets breakpoints. Packet capture asks for an explicit yes every time, and secrets are scrubbed from what the agent sees.

Does it need root?

Most tools don't. When one does, it prints the exact command for you to run, then reads the file with debuganything import. It never uses sudo itself.

Does anything leave my machine?

No. No cloud, no telemetry, no update checks. Raw output stays on your disk under ~/.debuganything.

How sure are the findings?

Each one says whether it was observed or inferred, and what the tools could not see. They are automated diagnostics, not professional advice. Read the evidence before you act.

No AI agent?

Run debuganything why <pid> yourself, install the Python package with pip install debuganything, or paste tool output into the analyzer.
