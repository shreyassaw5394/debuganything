Your agent runs it.

Debug Anything ships as an MCP server with two skills. Claude Code, Cursor, Codex and Gemini CLI can attach mid-task, run the right tool and answer with evidence instead of a guess.

{ "mcpServers": { "debuganything": { "command": "npx", "args": ["-y", "debuganything", "serve"] } } }
debuganything why <pid> --symptom slow   pick the tools, report, detach
debuganything attach <pid>               start a session
debuganything port 3000                  who holds a port
debuganything report --session $S        write the report

It only looks.

  • Read-only. Never kills, signals, patches or sets breakpoints.
  • No sudo, ever. If a tool needs root, you get the exact command to run yourself.
  • Asks first. Packet capture needs an explicit yes, every time.
  • Redacted. Tokens, keys and passwords are scrubbed from what the agent sees.
  • Local only. No cloud, no telemetry, no update checks.
  • Honest about limits. Each finding says observed or inferred, and what the tools could not see.

Questions.

Does it need root?

Most tools don't. When one does, it prints the exact command for you to run, then reads the result with debuganything import.

Which agents does it work with?

Claude Code, Cursor, Codex, Gemini CLI and anything that speaks MCP. There is also a Python package for LangChain, LlamaIndex, CrewAI or your own agent.

Does anything leave my machine?

No. Sessions, captures and reports stay under ~/.debuganything. It sends no telemetry.

Can CI use it?

Yes. Fail a job when memory grows between two snapshots, or use the GitHub Action, which attaches before a hung test is killed.

How sure are the findings?

Each one says whether it was observed or inferred and lists what the tools could not see. They are automated diagnostics, not professional advice. Read the evidence before you act.

No AI agent?

Run debuganything why <pid> yourself, or paste tool output into the analyzer, which runs in your browser.

Ask it why

Copies npx debuganything why 34327 --symptom slow. Or set it up for your agent with npx debuganything setup.
