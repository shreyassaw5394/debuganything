The agent asks. Debug Anything measures.

The agent never touches a tool directly. Debug Anything picks the right one, runs it inside hard limits, keeps the raw output on disk and returns a short result where every claim points at proof.

Questions.

Does it need root?

Most tools don't. When one does, it prints the exact command for you to run, then reads the file with debuganything import.

Which agents does it work with?

Claude Code, Cursor, Codex, Gemini CLI and anything that speaks MCP. There is also a Claude Code plugin and a Gemini extension.

What are the two skills?

debug-anything tells your agent when to look: a hang, a busy port, an out-of-memory kill. inspect-product audits a whole product as a new user and reports findings with reproductions.

Can CI use it?

Yes. Fail a job when memory grows between two snapshots, or use the GitHub Action, which attaches before a hung test is killed.

How sure are the findings?

Each one says whether it was observed or inferred and lists what the tools could not see. They are automated diagnostics, not professional advice. Read the evidence before you act.
